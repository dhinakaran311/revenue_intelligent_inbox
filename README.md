# Volopay Revenue Intelligence Inbox

This repository contains the implementation of the Revenue Intelligence Inbox as described in the implementation plan.

## Overview
- **Frontend**: Next.js application
- **Backend**: FastAPI service
- **Data**: Private assessment inputs (excluded from source control)
- **Analysis**: Reviewed analyses and routing policies
- **Exports**: Generated export bundles 
- **Docs**: Architecture and metric definitions
- **Scripts**: Setup, seed, replay, and export utilities
